# 双均线分析

**核心一句话**：均线是各周期市场参与者的平均持仓成本。**均线的方向就是价格的最小阻力方向。** 先认清趋势类型，再按类型选打法，最后用底扣价推演均线接下来往哪走。不机械等金叉、死叉。

方法来自一段中文教学视频（20/60/120 的 MA + EMA，TradingView），概念细节见 `references/concepts.md`，视频案例见 `references/cases.md`。

## 原则

1. **模糊的正确**：不预测明天涨跌，只判断接下来几周对多头还是空头有利。
2. **最小阻力方向**：均线向上时，不破坏上行的下跌是买点；均线向下时，每次上涨是卖点。
3. **趋势类型优先**：破线、拐头、交叉只是趋势转折的前三步，在横盘里会反复出现。没认清类型就照信号买卖，会被来回打脸。
4. **双算法互证**：同周期的 MA 和 EMA 都交叉（双交叉）才算确认；只有一组交叉、另一组离得远，多半是假动作。
5. **参数不是重点**：20/60/120 只是习惯，重点是看各周期成本的方向和次序。
6. **排列不合理不做**：短期线被中长期线压着时，再猛的反弹也多半撑不住，是减仓机会。
7. **仓位让心态稳得住**：浮盈浮亏影响心情，就是仓位太大，减到舒服为止。

## 流程

### 第 0 步：拿数据

`<SKILL_DIR>` 是本 SKILL.md 所在目录（Claude Code 和 Pi 加载 skill 时都会给出这个路径）。这是项目级 skill：真身在 `<项目>/.agents/skills/dual-moving-averages`（Pi 直接读），`<项目>/.claude/skills/dual-moving-averages` 是指向它的软链接（给 Claude Code 用）。

```bash
uv run --with pandas --with yfinance <SKILL_DIR>/scripts/dma_analyze.py <TICKER> [--asof YYYY-MM-DD]
uv run --with pandas <SKILL_DIR>/scripts/dma_analyze.py --csv prices.csv   # 列：Date, Close[, Volume]
```

脚本输出三段 Markdown：各周期 MA/EMA 数值和方向（钟表方向）、排列、间距、乖离率分位、最近交叉、成交量；**启发式**趋势初判和对应策略；三条 MA 的底扣价推演。

数据来源（报告第一行会写明用的哪个）：
- **默认先用 Polygon/Massive 付费 API**（`/v2/aggs` 复权日线）。`POLYGON_API_KEY` 按这个顺序找：环境变量 → `--env-file` → 当前目录及父目录的 `.env` → `~/Python/Playground/DualMovingAveragesTrading/.env`。
- Polygon 失败、没有 key，或返回的 K 线不够（付费档位只有最近约 5 年，回放更早的日期会 403），**自动回退 yfinance**，并写明回退原因。
- `--source polygon` 或 `--source yfinance` 强制只用一个数据源。

注意：
- **今日 K 线未完成**：最后一根 K 线是今天、且美东时间还没到 16:15（16:00 收盘，再加数据延迟 15 分钟）时，报告顶部会出现警告。这时"收盘价"其实是盘中价格。回答用户时要把这个警告放在结论前面，说明结论是"假如今天收在这里"，建议收盘后再确认。
- 两个数据源都是拆股/分红复权价，和视频或券商图上的绝对价格可能不同（例如 TSLA 2021 年的 700 美元在复权后约 233）。方向和相对关系不受影响。
- 脚本只分析日线。小级别（1h/30m）的加仓结构需要用户自己看图，或另取小时数据。
- 初判是规则算出来的，阈值写在脚本顶部常量里。边界情况（刚交叉、刚破线）要结合下面的判断表复核，必要时请用户看图。

### 第 1 步：看大局（现在是什么趋势）

看三样：**方向**（各均线指几点钟）、**排列**（短中长谁在上）、**乖离**（价格离 20 线多远）。

| 趋势类型 | 均线长什么样 | 打法 |
|---|---|---|
| 横盘震荡 | 3 点钟走平；均线缠绕收拢；量能低迷 | **基本不做**。末期出现标志性动作（大量、缺口、假跌破后收回），且突破前高前已形成或即将形成多头排列，才小仓位埋伏；突破失败、多头排列被破坏就离场。 |
| 健康上涨 | 2 点钟；多头排列（短>中>长）都向上；间距适中 | **持有，回调时结构性加仓**：日线回调到均线获支撑，切 1h/30m 等小级别走出破线→拐头→交叉→多头排列再加。不追高。 |
| 极度超买 | 1 点钟 ~ 12 点半；多头排列但价格大幅乖离 | **不追，只看不做**。有仓位分批止盈或上移止损。 |
| 健康下跌 | 空头排列都向下 | **不抄底**。反弹到均线附近是减仓、离场机会。 |
| 极度超卖 | 空头排列且价格大幅负乖离 | 不抢反弹，均线理顺成多头排列前不买。 |
| 过渡态 | 排列混乱或各线方向不一致 | 条件不满足就不做；靠第 3 步推演判断多久能理顺。 |

### 第 2 步：定策略

按上表确定：做不做、做多做空、在哪进场、仓位多大、什么情况离场。用户已有持仓时，把持仓成本和仓位纳入考虑。

### 第 3 步：看方向（底扣价推演）

N 日 MA 每天加进今天收盘价、扣掉 N 天前的收盘价（底扣价）。**收盘价 > 底扣价 → MA 上升；< → 下降。** 未来要扣的价格已经在图上。

- **扣低值**（未来底扣价低于现价）：股价不跌，均线就自然上翘，回调容易获支撑。
- **扣高值**：股价要涨过那些价格均线才不跌，稍微走弱就拐头向下。
- 推演链：底扣价 → 每条均线的方向 → 排列 → 趋势类型会不会变。
- 两个用途：**择时**（上涨中要扣高价平台就先防守，不急着加仓）；**提前看到切换**（横盘末期几条线即将一起扣低值上拐，就是埋伏时机）。
- 只对 MA 严格成立；EMA 没有精确底扣价，只作互证。

脚本里"价格不变时 MA 变化"和"第几天首次扣到低于现价"两列，就是视频里"往右数多少天才扣到低值区"的量化版本。

## 回答格式

```
**结论**：<趋势类型> → <一句话打法>

1) 看大局：方向 / 排列 / 乖离 / 最近交叉（双交叉与否）
2) 定策略：做不做、进场位置、加减仓条件、离场条件
3) 看方向：未来 10~20 天各均线扣高还是扣低，会不会拐头，趋势类型可能怎么变
风险提示：哪些情况会推翻这个判断（例如有效跌破 60 线、双死叉）
```

- 数字给到能核对的程度（均线值、底扣价、天数），不要堆满表格。
- 明确哪些是脚本规则算的、哪些是你的判断。
- 不给"一定涨/一定跌"的结论；这是概率和赔率的判断，不是投资建议。

## 常见误区（用户问到时要指出）

- 看到破线、拐头、交叉就买卖（先看趋势类型）。
- 纠结均线参数（重点是方向和次序）。
- 以为暴跌的成长股很快能涨回来（空头排列后要很久才能理顺）。
- 只看一组均线交叉（要双交叉）。
- 把"金叉进场、死叉离场"当万能纪律：在趋势里能保命，在横盘里会反复止损。
