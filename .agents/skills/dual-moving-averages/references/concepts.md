# 双均线概念速查

只讲概念是什么。规则（IF / THEN、出处）在 `rules.md`，按类型和仓位的打法在 `playbooks.md`。

## 底层逻辑

- 价格围绕市场平均成本波动。均线是各周期平均成本的近似值。
- 成本不断上升 = 牛市；成本不断下降 = 熊市。
- 均线的方向就是价格的最小阻力方向。
- "精确的错误不如模糊的正确"：只判断接下来几周成本往哪走、对谁有利，不预测明天。
- 观察系统就是取舍系统：只看价、量、时、空，图上谁看到的都一样（视频 G 00:32「所谓的观察系统 也就是一个取舍系统」；视频 G 02:21「价量时空 这4大要素 是最直接 最真实 最实时」）。
- 用均线不用趋势线：斜率是弧形的，趋势线千人千线（视频 G 06:14「很多人认为跌破趋势线怎么样 涨破趋势线又怎么怎么样 这都不科学」）。
- 长期均线的方向对价格有牵引作用（视频 H 07:43「这种长期移动平均线的运行方向 对股市，对价格运行有著 牵引作用」）。放到牛熊周期的尺度上，市场周期围绕长期趋势（均值）上下波动（视频 K 04:28「市场周期围绕着长期趋势 或者叫做均值上下波动」）。
- 消息、图形、基本面冲突时，图形最重要（视频 J 11:33「图形是投资者保护自己的最佳方式」）。情绪往往先于基本面选方向（视频 K 08:55「情绪会先于基本面 做出方向上的选择」）。
- 人性之极：信息和参与者都不完备，市场非理性，最终走向泡沫或崩溃两个极端（视频 G 45:24「也就是要么是泡沫，要么是崩溃」）。这恰恰是交易的最佳时机：低位到处是赚钱的机会，高位到处是亏钱的机会（视频 J 12:39「而人性之极 恰恰就是我们做交易的最佳时机」；视频 K 06:14「而在人性之极的低位时 市场上到处都是A袋子」）。恐慌时别恐慌，想想处在哪个阶段；疯狂时客观地问还该不该买（视频 G 45:49「人性之极才是你做投资做交易的最佳机会」）。
- 分析行情的目的是确立立场，然后才是何时进场（视频 J 13:07「分析行情不是占卜分析行情的目的是确立立场」）。三步走：确立最小阻力方向（均线方向）；找推动趋势的驱动力（反身性，不在图上）；找趋势最脆弱的地方（视频 J 14:44「第二个呢？就是要寻找这个趋势的反身性」；视频 J 15:03「然后第三就是寻找这个趋势的弱点」）。
- 要不要打是战略，怎么打是战术，频道讲的多数是战术（视频 E 12:45「我们讲的绝大多数关于交易的话题，其实都是战术问题」）。
- 趋势交易掐头去尾，严格说跑不赢市场，但它是风险最小的交易（视频 H 11:30「趋势交易 是风险最小的交易」）。

## 两种均线

| | MA / SMA | EMA |
|---|---|---|
| 算法 | 过去 N 天收盘价的算术平均，权重相同 | 指数加权，越近权重越大 |
| 方向由什么决定 | `MA(t) − MA(t−1) = [C(t) − C(t−N)] / N`：收盘价高于抵扣价就上升 | `EMA(t) − EMA(t−1) = α·[C(t) − EMA(t−1)]`，α = 2/(N+1)："价在线上，线向上；价在线下，线向下" |
| 门槛 | 抵扣价 C(t−N)。未来 N 天的门槛今天已经在图上 | 线本身。门槛随价格移动，明天的门槛要看今天收在哪 |
| 推演 | 要假设未来价格；给定一条价格路径，能精确算出每天的值 | 同样要假设未来价格；给定路径，同样能精确算出（持平时 EMA' = c + (EMA − c)(1 − α)^天数） |
| 灵敏度 | 慢，滞后 | 快，"所见即所得" |
| 角色 | 推演上是预判：抵扣价已知，能事先算出拐头价 | 时间上先拐（A4）；推演上用来验证 MA 的拐头是否有效 |

两者的差别不在"能不能推演"，而在门槛：MA 的门槛未来几天已知，EMA 的门槛跟着价格走。

时间上 EMA 先拐（A4）；推演上 MA 靠抵扣价预判，EMA 验证拐头是否有效（视频 G 13:22「也就是说我们有一个预判，有一个确认」；视频 G 13:53「用EMA均线 来验证这个拐头是否有效」）。EMA 跳上去线就上、跳下来线就下，作者把它当攻守的护城河（视频 L 04:29「攻守战略的护城河」）。

| 术语 | 含义 |
|---|---|
| 双均线 / 双线系统 | 同一周期同时画 MA 和 EMA，两种算法互相验证成本方向 |
| 周期 | 20（约一个月）/ 60（约一季）/ 120（约半年）。三段视频配色不同，不用记 |
| 线组 | "20 线组" = MA20 + EMA20，其余类推 |

## MA 的两道门槛

价格和一条 MA 的关系有两道门槛：线本身（价格在线上还是线下），和抵扣价（MA 往哪走）。两道各自独立，组合出四种情况：

| | 收盘高于抵扣价（MA 上行） | 收盘低于抵扣价（MA 下行） |
|---|---|---|
| 价在线上 | 正常上行 | 线上但已拐头（扣高值） |
| 价在线下 | 击穿但方向不变，即吃回撤区 | 破线且拐头 |

EMA 只有线本身一道门槛：价在线上，线就向上。

## 抵扣价（扣抵价、扣抵值，drop-off price）

C(t−N)，N 日 MA 明天要扣掉的收盘价，图上常标为小黄点。

- 收盘价高于它，MA 上升；低于它，MA 下降。不同软件可能差一根 K 线（标明天要扣的还是今天刚扣的）。
- 扣低值：股价不跌，均线自然上翘。扣高值：稍弱就拐头向下。
- 门槛路径：未来 K 天每天要扣的价格今天都已知。收盘守在其中最高值之上，这 K 天 MA 天天上行；守在最低值之下，天天下行。
- 小平台：收盘低于平台的最低点，抵扣价走过平台的这段时间，MA 天天下行。这是抵扣价的作用，不是破线。
- 判断拐头要动态看：想象抵扣价接下去怎么走，收盘要怎样走均线才能上去（视频 G 12:03「用抵扣价原理来判断 均线是否拐头这件事情 一定要动态来看」）。
- 抵扣价突然下降的位置，配上往上走的股价，均线会迅速拐头（视频 G 23:00「一个下移的抵扣价和一个上升的股价」）。这是狙击点（P31），也是 2B 有效的原因。

## 怎么量方向

| 钟表方向 | 趋势 |
|---|---|
| 12 点 ~ 1 点 | 加速上涨 |
| 1 点 ~ 2 点半（2 点钟约 30° 最典型） | 稳定上涨 |
| 2 点半 ~ 3 点半 | 横盘 |
| 3 点半 ~ 5 点（4 点钟左右典型） | 稳定下跌 |
| 5 点 ~ 6 点 | 加速下跌 |

斜率 = 涨跌幅 / 时间。可比的前提：**固定时长**和**对数坐标**（等比涨幅等高）。口诀："时钟方向、固定时长和对数坐标。"

方向和斜率是两个量：方向看最近几根拐没拐，斜率看固定窗口里走了多陡。

看趋势要数它走到现在经历了几波斜率变化（视频 I 04:02「走到目前这个状态经历了几波趋势的斜率变化」）。斜率变化用两个钟点描述，例如从 2 点钟往 1 点半走就是在加速（视频 I 05:17「两点钟方向 往一点半方向运行」）。强趋势看乖离，弱趋势看市场成本的密集程度（视频 I 03:31「弱趋势的时候我们要关注他的 密集程度，市场成本密集程度」）。

## 形态

| 术语 | 含义 |
|---|---|
| 多头排列 | 20 > 60 > 120，且都向上 |
| 空头排列 | 20 < 60 < 120，且都向下。长期 MA 没向下（价格仍高于 120 天前的收盘），空头排列就没走完（J35） |
| 排列不合理 | 次序错乱，例如 20 线组被压在 60 线组下方。市场会反复调整直到理顺 |
| 缠绕 / 收拢 | 几条线挤在一起，各周期成本接近。量化：最高最低均线相差 < 2% |
| 张嘴 / 发散 | 从收拢开始按次序拉开，趋势展开中 |
| 平行 | 稳定趋势里中长期均线近乎平行运行 |
| 失序 | 60/120 线组也乱了，定不出方向 |

## 信号

| 术语 | 含义 |
|---|---|
| 破线 | 收盘价穿过均线（转折第 1 步）。和"收盘低于抵扣价"不是一回事 |
| 拐头 | 均线方向反过来：MA 看收盘越没越过抵扣价，EMA 看价在线上线下（第 2 步） |
| 交叉 | 短线穿过中长线；上穿金叉、下穿死叉（第 3 步）。交叉不是买卖信号 |
| 双交叉 | 同一对周期的 MA 和 EMA 都交叉（例如 MA20 穿 MA60，EMA20 也穿 EMA60），才算交叉确认。不是"20×60 和 60×120 都交叉" |
| 五个进度点 | 脚本给一对线组记的转折进度：破线、EMA 拐头、MA 拐头、第一个交叉、双交叉。不是作者说的"五步" |
| 作者的五步 | 破线、拐头、交叉、多头 / 空头排列、乖离，就是下面的趋势生命周期（视频 L 18:35「趋势转变5个重要步骤」；视频 H 01:31「趋势转折的五个重要步骤」） |
| 两个动作 | 转折时 EMA 先拐（第 1 次机会），价格超过抵扣价后带动 MA 拐（第 2 次机会） |
| 不协同 | MA 和 EMA 方向不一致 |
| 假动作 | 一组快交叉、另一组离得很远，短期形成不了双交叉；或排列不合理时的强反弹。价格一侧：该突破的没突破、突破失败；该跌不跌又涨回去（视频 I 09:36「该突破的没突破，假突破，或者叫突破失败」；视频 I 09:45「他该跌不跌，然后又涨回去了」） |
| 乖离 / 乖离率 | （收盘价 − 均线）/ 均线。大幅乖离之后往往重新破线。两根均线之间的距离也叫乖离率（视频 L 02:37「这就是我们前面影片讲到的 乖离率」）。视频 G 的口径是收盘价对 EMA120，偏离 50% 以上算极端（J37） |
| 均值回归 | 大幅乖离后回到均线：价格急跌（急涨）找均线，或横着走等均线。回到均值不会停下，会穿越到另一端（视频 K 04:44「B：越过均值走向极端高位」；视频 K 04:52「E：继续穿越均值走向极端低位」） |
| 引力回归 | 大幅乖离而长期均线方向不变时，长期线把价格拽回（J36）。极端行为不能长期持续 |
| 关键性波动 | 能引起均线方向变化的波动，门槛是 EMA20 和 MA20 的抵扣价 |
| 支撑 / 压力 | 上涨回调到均线有人接；下跌反弹到均线有人卖 |
| MACD | 表达均线之间的聚散，即两根均线的距离（视频 L 02:05「移动平均线之间的聚散关系」）。用 EMA12、EMA26：DIFF = EMA12 − EMA26，DEA 是 DIFF 的 9 日平均，柱 = DIFF − DEA。研究的是趋势强度和强度的变化，强度不是趋势本身（视频 L 11:00「趋势强度不是趋势本身」）。它只表达交叉、排列、乖离，破线、拐头两步没表达（视频 L 18:57「破线、拐头，这两件事情在MACD上面没有表达出来」）。转色、背离不是买卖点（`rules.md` 不是规则） |
| 强度百分比 | （快线 − 慢线）÷ 慢线 × 100，能跨品种比趋势强度、做全市场排行（视频 L 20:27「评判全市场甚至是跨品种的趋势强度」） |

## 标志性动作与构造

| 术语 | 含义 |
|---|---|
| 大量 | 突然的巨量（"小草与大树"）。横盘末期出现是变盘信号；加速末端持续放量是分歧化解。成交量就是分歧，没分歧就没量（视频 G 29:47「认为成交量就是市场分歧」；视频 G 30:13「没有分歧的行情，不会有什么成交量」）；成交额比成交量更有意义。分歧越大，之后确定性越强（J43） |
| 缺口 | 跳空，中间留下无成交的价格空白 |
| 假突破 / 假跌破 | 两个动作有先后：先突破最近波峰后很快跌回，随后跌破 20 线组、20 线组下弯（假跌破镜像）。假跌破又叫破底翻：低点、反弹、再破前低、再反弹（P32） |
| 三种标志性动作 | 大量、缺口、假动作必须会认（视频 I 09:49「大量、缺口、假动作这三样东西是我们必须要有识别的」）。见到不寻常的图形，即使不知道发生了什么也要反应（视频 J 11:52「大量 缺口 某一些假动作」）。没有标志性动作，趋势不会改变（J41） |
| 人性之极 | 大跌之后，六点钟方向杀跌、迅速反弹、再杀跌、再快速拉起（视频 F 03:27「这就是我常说的叫做人性之极」）。是交易的最佳时机（见底层逻辑） |
| 筹码峰 | 多次试探过的位置。突破它就占领了筹码峰（J42） |
| 顶部 / 底部构造 | 见下一节。构造是"路牌"，不是"路"；动手看均线 |
| 密集成交区 | 横盘区间，多空换手统一成本，常对应大筹码峰。大周期的休息站 |

## 顶底构造与波段

只看每根 K 线的最高价和最低价。

| 术语 | 含义 |
|---|---|
| 顶部构造 | 新高之后，先出现更低的高点，再出现更低的低点，最少三根 K 线 |
| 底部构造 | 镜像：新低之后，先出现更高的低点，再出现更高的高点 |
| 包含结构 | 被最后一根新高（新低）K 线的高低点包住的 K 线忽略，只看打破它的那一根 |
| 极端构造 | 第二根创新高却跌破前一根低点，仍要第三根创出更低的低点来确认 |
| 构造破坏 | 顶部构造之后又创出更高的高点，构造作废，从新高点重新找 |
| 构造与顶底 | 构造完成不等于见顶；构造没完成之前不可能是顶 |
| 提前算 | 构造只差一根时，能算出"再出现一根怎样的 K 线就完成" |
| 波段 | 顶部构造的最高点连到底部构造的最低点。最小波段 6 根 K 线，两个构造不共用 K 线 |
| M 顶 / W 底 | 顶部构造、底部构造、顶部构造，收盘跌破中间那个底（颈线）才算形成。W 底镜像 |
| 2B | 创出高点 A，明显回撤到 B（B 不是底部构造），迅速创新高 C，随后迅速跌破 A。底部 2B 跌破前低后马上回来、之后不再创新低才成立（视频 G 26:29「这个时候已经不再创低点了 依然高于低点，2B结构就成立了」）；它有效，是因为反弹时 20 抵扣价正要下坠，20 线会强烈拐头。2B 只解决回归（J39） |

用词提醒：视频 G 化石一例把"20 线拐头、底部逐步成形"也叫底部构造，那是泛称，不是上面只看高低点的 K 线构造。

## 多周期

| 术语 | 含义 |
|---|---|
| 趋势扩散 | 趋势由小级别向大级别扩散：EMA20 → MA20 → 60 线组 → 120 线组。跨时间周期也一样：5 分钟 → 15 分钟 → 60 分钟 → 日线 → 周线 → 月线（视频 E 01:49「15分钟的趋势逐渐走好会带动60分钟」）。要动态看扩散，不在一个周期里静态看（视频 E 04:58「而不是在一个周期里面静态地去观察」） |
| 周期共振 | 小、中、大至少三个级别同步完成一个重要动作（J33），要第一时间反应（P36） |
| 下一级别的均线密集 | 看周线能不能拐头，先看日线有没有均线密集（J34）；也是下跌后两种买入信号之一（P33） |
| 结构性加仓 | 大级别回撤获支撑时，在小级别（1h/30m）等破线 → 拐头 → 交叉 → 多头排列再加 |
| "第一次"回撤 | 新趋势确立后第一次回到 20 / 60 / 120 线组，是非常好的入场点（视频没说胜率） |
| 周线 | 大一级的结构。横盘结束后往哪走，跟周线的排列走 |

大级别定方向，小级别找进场点。

## 趋势生命周期

破线 → 拐头 → 交叉 → 多头 / 空头排列 → 大幅乖离 →（再次破线，下一轮）

作者说的趋势转折五步就是这条链。多头排列这一步产生赚钱效应，赚钱效应过强引来羊群，价格就大幅偏离平均成本（视频 H 02:04「进行多头排列 产生赚钱效应」；视频 H 02:18「最后导致价格大幅偏离市场平均移动成本」）。

完整牛熊循环：加速冲顶 → 顶部构造 → 破线拐头交叉 → 空头排列 → 横盘 → 假突破后破位 → 加速下跌放量 → 底部构造 → 破线拐头交叉 → 多头排列 → 横盘统一成本 → 稳定牛市。

视频 G 把一波趋势分成五个阶段：转折、开始、发展、极端、转折（视频 G 02:46「转折-开始-发展-极端-转折」）。斜度从低角度到中角度再到高角度，乖离到很高之后可能往下走（视频 I 04:16「趋势的斜度是从一个低角度到中角度、再到高角度的这样的一个过程」）。

转向是渐进的：反向因素逐渐进来，先改变斜率，再改变成本的运行方向和排布（视频 J 08:34「逐渐去改变它 改变它的斜率」；先后按作者列举的次序读）。市场像钟摆，在乐观贪婪和悲观恐惧两个人性之极之间摆动（视频 K 05:03「从乐观贪婪的人性之极 摆动到悲观恐惧的人性之极」）。

加速出现在趋势两头：刚突破密集区时，或冲顶、崩盘时。视频 G 的示意不一样：开始阶段较缓，发展阶段是真实斜率，到极端斜率突然加大（视频 G 04:07「开始阶段是比较缓的 发展阶段才是它真实的斜率」）。J8 按视频 B 08:59 保留"起点"，两说并存。

## 空间与目标位

| 术语 | 含义 |
|---|---|
| 空间 | 市场平均成本在不同时期的落差：一个成本趋于一致的区域到下一个的距离（视频 G 38:36「市场平均成本在不同时期的落差」）。股价从底部上来，要逐个征服下跌途中形成过均线密集的区间（视频 I 08:30「曾经产生过均线密集的哪些区间」） |
| 目标位 | 第一个是缺口或上方最近的均线密集，下一个是 20/60/120 全部汇聚处（P25）。先拿下阵地，再拿下山头（视频 G 40:58「先拿下这个阵地，再拿下山头」） |
| 盈亏比 | 上方到目标位的空间 ÷ 做错要认的亏损（视频 I 11:59「这个上部空间除以你的下部亏损空间这就是盈亏比」）。小于 3:1 不做，最好 5:1 以上（P24）。下跌转上升时抓到底部，盈亏比非常高（视频 I 13:17「那个底部如果说被你抓住了，盈亏比是非常高的」） |
| 必由之路 | 上涨或下跌都必须经过的关键位置，用抵扣价推演能算出来，在那里等它（P30） |

## 五种趋势类型

加速上涨、稳定上涨、横盘、稳定下跌、加速下跌。类型看 60/120 线组，阶段看 20 线组和价格；定不出类型时是多头结构回撤中、空头结构反弹中、顶部 / 底部转折中或失序。判法见 `rules.md` J1–J7，类型总表见 SKILL.md 第 1 步，打法见 `playbooks.md`。
