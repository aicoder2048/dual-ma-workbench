# 双均线概念速查

## 均线

| 术语 | 含义 |
|---|---|
| MA / SMA | 过去 N 天收盘价的算术平均，每天权重相同，有严格的底扣价 |
| EMA | 指数加权平均，越近权重越大，反应快，没有精确底扣价 |
| 双均线 | 同一周期同时画 MA 和 EMA，两种算法互相验证成本方向 |
| 周期 | 20（短，约一个月）/ 60（中，约一季）/ 120（长，约半年）。视频图上颜色：黑灰 / 红 / 蓝 |

## 底扣价（扣抵值，drop-off price）

```text
MA(t) − MA(t−1) = [C(t) − C(t−N)] / N
```

C(t−N) 就是底扣价，图上常标为小黄点。收盘价高于它，MA 上升；低于它，MA 下降。不同软件可能差一根 K 线（标明天要扣的还是今天刚扣的）。

## 形态

| 术语 | 含义 |
|---|---|
| 方向（钟表） | 3 点钟走平；2 点钟约 45° 稳定上行；1 点钟 ~ 12 点半接近垂直（超买）。下跌镜像为 4 点钟、5 点钟（类推说法） |
| 多头排列 | 短 > 中 > 长，且都向上 |
| 空头排列 | 短 < 中 < 长，且都向下 |
| 排列不合理 | 次序错乱，市场会反复调整直到理顺 |
| 缠绕 / 收拢 | 几条线挤在一起，各周期成本接近，没有方向；横盘特征，也是变盘前兆 |
| 发散 | 按次序拉开，趋势展开中 |

## 信号

| 术语 | 含义 |
|---|---|
| 破线 | 收盘价有效跌破/突破均线（趋势第 1 步） |
| 拐头 | 均线斜率反向，由收盘价与底扣价比较决定（第 2 步） |
| 交叉 | 短线穿中长线；上穿金叉、下穿死叉（第 3 步） |
| 双交叉 | MA 组和 EMA 组都交叉，才算确认 |
| 假动作 | 只有一组交叉、另一组离得远，或排列不合理时的强反弹 |
| 乖离 / 乖离率 | （收盘价 − 均线）/ 均线。大幅乖离是第 5 步，之后往往重新破线 |
| 支撑 / 压力 | 上涨回调到均线有人接；下跌反弹到均线有人卖 |
| 标志性动作 | 大量（"小草与大树"）、跳空缺口、假跌破/假突破；横盘结束或趋势转变的信号 |
| 结构性加仓 | 大级别回调获支撑时，在小级别（1h/30m）等破线→拐头→交叉→多头排列再加仓 |

## 趋势生命周期

破线 → 拐头 → 交叉 → 多头/空头排列 → 大幅乖离 →（再次破线，下一轮）

## 五种趋势类型

横盘震荡、健康上涨、极度超买、健康下跌、极度超卖。另有排列混乱的过渡态。判断表和打法见 SKILL.md 第 1 步。
