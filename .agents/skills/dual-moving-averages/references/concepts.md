# 双均线概念速查

## 底层逻辑

- 价格围绕市场平均成本波动。均线是各周期平均成本的近似值。
- 成本不断上升 = 牛市；成本不断下降 = 熊市。
- 均线的方向就是价格的最小阻力方向。
- "精确的错误不如模糊的正确"：只判断接下来几周对谁有利，不预测明天。具体做法：数 6 条成本线的**方向**，看短中长期线组的**排布**（贴在一起的不算错位），合成偏多 / 偏空 / 不明。见 SKILL.md"模糊判断"。

## 两种均线

| | MA / SMA | EMA |
|---|---|---|
| 算法 | 过去 N 天收盘价的算术平均，权重相同 | 指数加权，越近权重越大 |
| 方向由什么决定 | `MA(t) − MA(t−1) = [C(t) − C(t−N)] / N`：收盘价 > 抵扣价就上升 | `EMA(t) − EMA(t−1) = α·[C(t) − EMA(t−1)]`，α = 2/(N+1)："价在线上，线向上；价在线下，线向下" |
| 灵敏度 | 慢，滞后 | 快，"所见即所得" |
| 能否提前推演 | 能，未来要扣的价格已在图上 | 不能精确推演 |
| 角色 | 确认 | 先行 |

| 术语 | 含义 |
|---|---|
| 双均线 / 双线系统 | 同一周期同时画 MA 和 EMA，两种算法互相验证成本方向 |
| 周期 | 20（约一个月）/ 60（约一季）/ 120（约半年）。三段视频配色不同，不用记 |
| 线组 | "20 线组" = MA20 + EMA20，其余类推 |

## 抵扣价（扣抵价、扣抵值，drop-off price）

C(t−N)，N 日 MA 明天要扣掉的收盘价，图上常标为小黄点。

- 收盘价高于它，MA 上升；低于它，MA 下降。不同软件可能差一根 K 线（标明天要扣的还是今天刚扣的）。
- 扣低值：股价不跌，均线自然上翘。扣高值：稍弱就拐头向下。
- 过滤器：上涨中回踩甚至击穿 60/120 线，只要价格仍高于抵扣价，MA 继续向上。

## 怎么量方向

| 钟表方向 | 趋势 |
|---|---|
| 12 点 ~ 1 点 | 加速上涨 |
| 1 点 ~ 2 点半（2 点钟约 30° 最典型） | 稳定上涨 |
| 2 点半 ~ 3 点半 | 横向震荡 |
| 3 点半 ~ 5 点 | 稳定下跌 |
| 5 点 ~ 6 点 | 加速下跌 |

斜率 = 涨跌幅 / 时间。可比的前提：**固定时长**（长期看 5 年、短期看 1 年）和**对数坐标**（等比涨幅等高）。口诀："时钟方向、固定时长和对数坐标。"

## 形态

| 术语 | 含义 |
|---|---|
| 多头排列 | 20 > 60 > 120，且都向上 |
| 空头排列 | 20 < 60 < 120，且都向下 |
| 排列不合理 | 次序错乱，市场会反复调整直到理顺 |
| 缠绕 / 收拢 | 几条线挤在一起，各周期成本接近，没有方向。量化：最高最低均线相差 < 2% |
| 张嘴 / 发散 | 从收拢开始按次序拉开，趋势展开中 |
| 平行 | 稳定趋势里中长期均线近乎平行运行 |

## 信号

| 术语 | 含义 |
|---|---|
| 破线 | 收盘价有效跌破/站上均线（趋势第 1 步） |
| 拐头 | 均线斜率反向：MA 看抵扣价，EMA 看价在线上线下（第 2 步） |
| 交叉 | 短线穿中长线；上穿金叉、下穿死叉（第 3 步） |
| 双交叉 | MA 组和 EMA 组都交叉，才算确认 |
| 两个动作 | 转折时 EMA 先拐（第 1 次机会），价格超过抵扣价后带动 MA 拐（第 2 次机会） |
| 不协同 | MA 和 EMA 方向不一致，该做保护或减仓 |
| 空头结构反弹中 | 60/120 定不出类型，20 线组已在 60 线组下方（双死叉），价格反弹。排列不合理时的强反弹，多半是假动作 |
| 多头结构回撤中 | 镜像：20 线组仍在 60 线组上方，价格回撤。结构还是多头，看 20/60 会不会双死叉 |
| 假动作 | 只有一组交叉、另一组离得远，或排列不合理时的强反弹 |
| 乖离 / 乖离率 | （收盘价 − 均线）/ 均线。大幅乖离是第 5 步，之后往往重新破线 |
| 均值回归 | 大幅乖离后回到均线：价格急跌（急涨）找均线，或横盘等均线 |
| 关键性波动 | 能引起均线方向变化的波动。只在它上面动手 |
| 支撑 / 压力 | 上涨回调到均线有人接；下跌反弹到均线有人卖 |

## 标志性动作与构造

| 术语 | 含义 |
|---|---|
| 大量 | 突然的巨量（"小草与大树"）。横盘末期出现是变盘信号；加速末端持续放量是分歧化解、要转向 |
| 缺口 | 跳空，中间留下无成交的价格空白 |
| 假突破 / 假跌破 | 突破前高后很快跌回 + 20 线组下弯（反之亦然）。两个动作都要 |
| 顶部 / 底部构造 | 顶底形态（如 W 底）。是"路牌"，不是"路"；动手看均线 |
| 密集成交区 | 横盘区间，多空换手统一成本，常对应大筹码峰。大周期的休息站 |

## 多周期

| 术语 | 含义 |
|---|---|
| 趋势扩散 | 趋势由小级别向大级别扩散：EMA20 → MA20 → 60 线组 → 120 线组 |
| 结构性加仓 | 大级别回调获支撑时，在小级别（1h/30m）等破线 → 拐头 → 交叉 → 多头排列再加 |
| "第一次"回撤 | 新趋势确立后第一次回到 20 / 60 / 120 线组，胜率最高 |

大级别定方向，小级别找进场点。

## 趋势生命周期

破线 → 拐头 → 交叉 → 多头/空头排列 → 大幅乖离 →（再次破线，下一轮）

完整牛熊循环：加速冲顶 → 顶部构造 → 破线拐头交叉 → 空头排列 → 横盘 → 假突破后破位 → 加速下跌放量 → 底部构造 → 破线拐头交叉 → 多头排列 → 横盘统一成本 → 稳定牛市。

## 五种趋势类型

加速上涨、稳定上涨、横盘、稳定下跌、加速下跌；定不出类型时是多头结构回撤中、空头结构反弹中、顶部 / 底部转折中或失序。判法见 `rules.md` J1–J7，判断表见 SKILL.md 第 1 步，打法细则见 `playbooks.md`。
