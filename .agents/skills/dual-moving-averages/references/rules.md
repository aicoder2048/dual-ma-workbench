# 规则

每条规则一个编号。种类：**公理**是数学事实；**判定**的结论是状态；**动作**的结论是该做什么。

- 来源写视频代号、时间戳和一句原话（A–L、O、P，见 `cases.md` 开头的代号行；N 是另一位作者，只出现在"外部交叉引用"一节和对照里）。原话都用 `dma-video-ingest` 的 `verify_quotes.py` 对字幕核过。视频 C 没有字幕，来自它的规则标"视频 C，未核对字幕"。字幕里找不到的写"推断"。
- "由哪个计算判断"写 `scripts/rules.py` 里的函数。写"需看图"的脚本算不了，规则清单里状态固定为"需看图"。A6、P22–P25 的价位在 `scripts/tradeplan.py`（交易计划，JSON 的 `trade_plan`）里算一次，`rules.py` 的函数只把空仓那份计划写成规则状态。
- 脚本给每条规则算出 `{编号, 状态, 依据, 价位, 让位}`，状态是 满足 / 不满足 / 需看图。公理永远成立，状态写"满足"，依据里写今天套用的结果。
- 两条动作规则同时满足、结论相反时，THEN 里写了谁优先。脚本在让位的那条上标出优先的编号（JSON 的 `yields_to`，规则清单写"满足，P17 优先"）。
- 成对的规则（上涨 / 下跌、顶 / 底）写多头一侧，标"镜像"的按方向反过来读。脚本按类型线的方向取一侧。作者股票只做多、大的期货品种才双向做（视频 J 13:31），做股票时空头一侧读成离场、不做多。
- 文中的数凡是脚本定的，都在文末"阈值"表里，标明是视频里的数、校准值还是脚本自定。
- THEN 末尾标 **回测不支持**（评估 2026-11-20，H5 / H6）的：2026-11-20 的评估（`scripts/evaluate.py`，门槛在 `evaluation.toml`）没找到这条主张成立的证据。规则照常算、照常显示，逻辑没改；回答里说明回测不支持，不单独据此给结论。H5 测的是"横盘之后的突破方向跟周线排列走"，对应 J11（回放的周线改用 5 年历史后重跑过，结论不变）。H6 测的是"空头结构反弹中、下跌·反弹中之后 20 日跑输"，对应 J18 和以它为依据的 P17，J17 说的也是这种反弹是假动作。

"20 线组"指 MA20 + EMA20，其余类推。

## 筹码分布

按价格统计成交量，概念见 `concepts.md` 标志性动作与构造、空间与目标位。为什么只当价位和目标参考、不给买卖信号，见 `docs/adr/0015.md`。

脚本（`volprofile.py`）：统计区间的最低价到最高价等分 `PROFILE_BINS` 档，每根 K 线的量按价格均匀摊在它的 [最低价, 最高价] 上；量 ≥ `PROFILE_EDGE` × 各档平均量的连续几档是一座山，最下面那档的下沿是山脚、最上面那档的上沿是山顶。规则和交易计划没有"可见范围"，统计区间固定为最近 `PROFILE_DAYS` 个自然日，和工作台日线默认的「1 年」视图同一段；工作台图上的筹码分布按可见范围在浏览器里重算（`app/public/volprofile.js`，和 Python 用同一份夹具对过）。

## 不是规则

- **金叉买、死叉卖**：视频里没有这条。交叉是转折第三步（J15）、埋伏的底线（P3）、真假动作的判别（J17）。
- **收盘跌破小平台就是破线**：小平台的意义在抵扣价。收盘低于平台最低点，抵扣价走过平台的这段时间 MA 天天下行（A2）。破线另指价格穿过均线（J15）。
- **用账户亏损的百分比定止损**：几个百分点可能只是正常波动，不影响趋势，这个数也没有依据。止损放在趋势结构上（P23）。视频 F 04:56「有可能只是市场的一次正常的波动并不会影响趋势的发展」。
- **浮盈后把止损提到成本价保本**：视频没讲这一条。成本价不是趋势依据，止损按 P23，成本价只用来算仓位（A6）。
- **MACD 红柱转绿、DIFF 死叉 DEA 就卖**：只说明快慢线距离在缩小、强度减弱，不等于趋势改变。视频 L 13:31「但是趋势减弱了 并不等于趋势被改变了」；视频 L 13:11「来作为买卖点 这是大错特错的」。
- **筹码分布给买卖信号**：筹码分布只给位置和阻力大小（J45–J49），方向仍看均线。视频 O 03:21「不要迷信任何指标 它们只是工具」；视频 O 03:25「最重要的呢？还是要判断出大势的方向」。
- **MACD 背离是转折信号**：背离只说明两个时点的强度不一样。视频 L 16:03「你怎么能够把两个不一样的强度」。
