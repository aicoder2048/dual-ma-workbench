# 0035 「看图学交易」8 期入库：筹码峰共振买回撤、抵抗性 K 线止损先照实写进文档，交易计划下一个 PR 再接

- 状态：采纳（随 PR 合并生效；不合并就改写成"不做"）
- 日期：2026-11-22

## 背景
- LEI 频道里有 8 期未公开列出的「看图学交易」（代号 Q–W、Y，2025 年 10–11 月，NVDA、AMD、IREN、RIVN、QQQ、BTC 及相关股、CRWV、七巨头）。条目 151 条，原话都用 `verify_quotes.py` 对字幕核过，每期只有一条推断（案例日期或口述价位）。
- 和现有文档有两处冲突：
  1. 现有写法是"筹码分布只给位置和阻力，不给买卖信号"（`concepts.md` 底层逻辑、`rules.md` 不是规则，依据 ADR 0015）。这 8 期里有 7 期都说两点钟方向的大多头买回撤，买在重要均线和重要筹码峰共振的位置（视频 Y 04:05、视频 U 02:22 等）。
  2. `playbooks.md` 交易计划表写"视频没给吃回撤的止损价位"。视频 S 08:22 给了：跌破反弹的第一根大阳线；视频 Y、R、V 也把止损放在抵抗性 K 线（或十字星）的最低价。

## 决定
用户 2026-11-22 定：两处都按字幕改，也都要接进交易计划。分两步走，这一步只改文档，不动计算。
- 文档照字幕改：去掉"不给买卖信号""视频没给止损"；新增 P46（共振位置买回撤）、P47（等抵抗性 K 线进场，止损在它最低价）、P48（持仓底线不跌破筹码峰平台）、P49（三点钟方向做突破不做回撤）、J50–J52（筹码峰是公允价格、下方筹码峰止跌、死叉后筹码峰挡不住）。这几条都是"需看图"，`rules.py` 只登记编号。
- `concepts.md` 加"抵抗性 K 线""放弃阵地"，筹码峰写清两种用法；`cases.md` 加 8 个案例。
- 作者读钟点的实例（视频 S 03:14、视频 Y 03:41、03:52、07:21）记在 J2 的来源里，可作校准点，还没进校准表。
- 不写入：期权做法（视频 S，skill 不做期权定价）；基本面（视频 W，skill 不做估值）。
- 下一个 PR 把 P46、P47 接进交易计划（吃回撤的进场位置、止损）：先把"重要筹码峰""共振""抵抗性 K 线"定义成能算的条件，在核心名单上回测，和 main 的基线比，再由用户决定合不合并。到时另写 ADR，必要时把 ADR 0015 / 0018 标为部分推翻。

## 理由和出处
- 字幕是唯一依据（`dma-video-ingest`）：现有写法和字幕不一致，以字幕为准。
- 先文档、后计算：计算要先定义"共振""抵抗性 K 线"，还要回测，混在一个 PR 里难审；文档照实写不改任何结论和回测结果。
- 回测先跑核心名单，不过就停（用户偏好）。

## 什么情况下重新考虑
- 下一个 PR 的回测：接入后核心名单变差，就只保留文档，计算不接，回到"需看图"。
- 以后有视频说筹码峰共振只是参考、不是买点。
