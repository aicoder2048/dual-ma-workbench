# 0015 筹码分布只作价位和目标位参考，不给买卖信号；按可见范围计算

- 状态：采纳
- 日期：2026-11-20

## 背景
视频 O（LEI，筹码分布 Volume Profile）入库，工作台要画筹码分布，并把筹码山接成目标位来源。要先定它在方法里的位置和统计区间。

## 决定
筹码分布只给价位：山脚、山顶、反弹目标区间、翻过山头、山在价格上方还是下方（rules.md J45–J49、P38、P39）。它不单独给买卖信号，方向仍看均线。统计区间取图上可见的那段 K 线，缩放、平移后重算。

## 理由和出处
作者说"不要迷信任何指标 它们只是工具"（视频 O 03:21），最重要的还是判断大势方向（视频 O 03:25）。他用的是 TradingView 的可见范围筹码分布（视频 O 03:08「我使用的就是这个 View Range Volume Profile」）；只算可见范围是从指标名推出的，视频没说看多长、从哪个波段算起。

## 影响
规则先标"需看图"，计算待叠加层 PR 接入。划山脚、山顶的成交量阈值（`PROFILE_EDGE`）由脚本自定，在叠加层 PR 里定。筹码下沉、山峰汇聚要比较两个时点的分布，只记概念，不做。

## 什么情况下重新考虑
LEI 的视频里说明了筹码分布的统计区间（看多长、从哪个波段算起），或拿筹码分布给出明确的进出场规则，并且入库核过原话。
