# 0036 P46 筹码峰共振、P47 抵抗性 K 线止损不接进交易计划：核心名单回测没测出好处

- 状态：不做（用户 2026-11-22 定）
- 日期：2026-11-22

## 背景
- ADR 0035 把「看图学交易」8 期照字幕写进文档：P46（两点钟大多头买回撤，买在重要均线和重要筹码峰共振的位置）、P47（回撤到位等抵抗性 K 线，止损在它的最低价）。用户 2026-11-22 定：两条都试着接进交易计划，先在核心名单上回测，再定合不合并。
- 交易计划原来的吃回撤：P10–P13 四个条件，进场后止损放在 60 线组拐头（解读，因为当时以为视频没给价位）。

## 决定

两条都不接进交易计划，留在 `rules.md` 作需看图的规则，可以作看图参考。吃回撤仍是 P10–P13 四个条件，止损仍是 60 线组拐头（解读）。ADR 0015、0018 不变。

## 试过的做法（定义在跑回测之前写死，没有按结果调）
- **P46 共振**（`rules.p46_resonance`）：P11 之上加的过滤。这次回撤（`_pullback_start` 起）收盘碰到 60 或 120 线组（MA、EMA 较高的那条，和 P11 一样）的那几根，当天线组的价位落在一座筹码山（`volprofile.plan_profile`，信号日往前 1 年，`find_mountains` 现成的结果）的山脚到山顶之间，算共振。不设"重要"的大小门槛（字幕没给数）；不新增"跌到 120 线也能买"的路径。回撤到 60 线组却不共振，空仓不进。
- **P47 止损**（`rules.p47_resist_stop`）：这次回撤最低点之后第一根抵抗性 K 线的最低价。抵抗性 K 线（脚本自定）：大阳线 = 阳线、实体 ≥ 1 个 Wilder ATR(14)、收盘越过前一根最高价；或长下影线 = 下影 ≥ 1 个 ATR 且 ≥ 2 倍实体。放量是"最好"，不要求。只换空仓进场后的止损；持仓的底线仍是 60 线组拐头。还没有这根 K 线时退回 60 线组拐头（reason 写明）。"收盘前确认就买"没接。
- 盈亏比、P24、股数都按换过的止损重算。
- 回测：fullplan 加了两个默认关的开关，四组从同一份每日缓存派生；开关关着时，核心名单 125206 个决定点逐天和接入之前的计划比，0 处不同。这份代码没有合并（分支 `feat/pullback-resonance-stop`，提交 65fcfef，只在本机），要重测时从这里取。

同一批品种上 MA200 朴素规则的 MAR 是 0.78，四组都远低于它。

MAR 的变化从哪来：
- **P46**：共振过滤掉 310 张单，吃回撤少了 36 笔；剩下的吃回撤单笔平均 R 从 3.64 降到 3.05，总 R 从 1124 降到 834。过滤掉的是平均更好的单，MAR 下降主要来自少了好单和单笔 R 变小，回撤几乎没变。
- **P47**：吃回撤 317 笔里 266 笔信号日还没有抵抗性 K 线，退回 60 线组拐头，真正用上新止损的只有 51 笔。止损更近，单笔平均 R 从 3.64 降到 2.38（被止损的多了），年化从 10.8% 降到 9.5%，但最大回撤从 −32.9% 缩到 −25.9%，MAR 从 0.33 升到 0.37。MAR 的提升来自回撤变小，不是赚得更多；平均 R 的 90% 区间下沿碰到 0。
- **两个都加**：两边的坏处叠在一起，MAR 0.24，平均 R 区间跨 0。

## 理由和出处
- 字幕是唯一依据：视频 Y 04:05、U 02:22（共振）；视频 S 08:22、Y 20:12（抵抗性 K 线止损）。可算条件里的阈值是脚本自定，见 `rules.md` P46、P47。
- 回测先跑核心名单，不过就停（用户偏好）。核心名单的关口（平均 R 区间整个在 0 以上、MAR 不低于 MA200）四组都没过，所以没补测其余品种。
- 这只是开发集上的证据：新的验证集已经用过（`references/holdout-runs.json`），没有再拿来验。

## 为什么不接
- P46 滤掉的是平均更好的单，MAR 0.33 → 0.24。
- P47 只改了约六分之一的吃回撤单；回撤小了，但年化和单笔 R 都降了，平均 R 的区间碰到 0。MAR 小幅上升不足以抵消，而且四组都远低于 MA200 的 0.78。
- 定位是真实交易的工具（ADR 0001）：没测出好处的改动不进计划，LEI 的原话留在文档里供看图参考。

## 什么情况下重新考虑
- 用户觉得"共振"的读法不对（例如要看 60 周线、要求"重要"筹码峰的大小门槛、要按触线当天的筹码分布而不是信号日的），改定义要另找没用过的数据验证，不能在这份核心名单上反复调。
- 以后有新的验证集，可以再测一次。
