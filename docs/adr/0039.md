# 0039 找打法的仓位格加一行仓位比例：用账户的百分之几，不需要账户总额；只改显示

- 状态：采纳
- 日期：2026-11-22

## 背景
「仓位」格只给股数（A6）：填了账户给股数，没填只给"每 1 万元风险对应 N 股"。用户问股数干什么用、能不能用比例。股数是为了让每一笔止损时亏的钱正好是事先定的那么多；用的人更关心的往往是"拿账户的百分之几去买"，而这个比例不需要知道账户有多大。

## 决定
空仓会买时，「仓位」格在股数后面加一条「仓位比例」。

- 仓位占账户 = 每笔愿意亏的比例 ÷ 止损幅度，止损幅度 =（进场 − 止损）÷ 进场。写成"用账户的 50%（止损幅度 2%，每笔亏账户的 1%）"。
- 设置按比例时直接用那个比例，没填账户也显示：工作台现在总把 `--risk-pct` 交给脚本（原来没填账户什么都不传，脚本用默认 1%）。按固定金额时，填了账户就换算成比例；没填账户算不出比例，这一条不写。
- 超过 100% 如实写"要用账户的 250%……超过账户：按买得起的最多股数"，和股数"账户封顶"一个口径。
- 触发价离现价还远时和股数一样写"到时重算"（ADR 0026）；不进场、没有止损的打法没有这一条。持仓不加。
- 数字由脚本算（`tradeplan.size_position` 的 `stop_pct`、`risk_pct`、`account_pct`），`plan.ts` 只配措辞；长风的数据字段多一条 `计划.仓位比例`。股数、盈亏比、交易计划、回测都不变。

## 理由和出处
- 视频 F 05:56「请注意是金额不是比例」说的是除的时候用金额：可承受亏损先换成钱，再除以单位亏损。这里的比例只是同一笔风险换一种说法，风险金额的口径不变，股数照旧按金额算。
- "用账户的 50%"比"每 1 万元风险对应 13513 股"好懂，而且不用填账户总额。
- 概念图解不讲股数和仓位：它们是资金管理的算术，不是看图要认的技术术语（用户 2026-11-22）。

## 什么情况下重新考虑
- 用户想在结论卡片那一排也看到比例（现在那一排最挤，只在找打法的仓位格里写）。
- 设置里要支持"按账户百分比给仓位上限"之类的规则时，另写一条。
