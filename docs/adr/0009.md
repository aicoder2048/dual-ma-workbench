# 0009 新验证集只跑一次；锁定是警告加计数，不是阻断

- 状态：采纳
- 日期：2026-11-20

## 背景
第 4 步用 50 只从没测过的票做最终检验，结论"新验证集不支持"（平均 −0.18R，MAR 0.16，MA200 0.54）。

## 决定
验证集名单和判定标准在出结果前提交；跑完锁定：回测页对这批票弹警告，运行次数写进 `references/holdout-runs.json`。不阻断。

## 理由和出处
阻断会逼人绕过；提交进仓库的运行次数让任何重跑都在 git 里可见。结论不再回头调规则去凑这批票。

## 影响
以后再改规则，需要另一份新数据来验证。PR #48。

## 什么情况下重新考虑
有了足够多的新数据（例如之后一两年的行情）可以另建验证集。
