# 0032 「模糊判断」在界面上改叫「大方向」

- 状态：采纳（随 PR 合并生效；不合并就改写成"不做"）
- 日期：2026-11-21

## 背景
LEI 的理念是"精确的错误不如模糊的正确"（视频 C 01:43），重点在"正确"：方向对，数字不求精确。界面上叫「模糊判断」，只留了"模糊"，字面读成"不靠谱的判断"，和原意相反。它又是结论卡片标题后半段、做推演的第一句，第一眼就看到。

## 决定
只改显示的名字，不动计算、字段（`visual.lean`）、长风的字段 id（`模糊判断`、`模糊判断.方向` 等）和评估、回放报告。
- 结论卡片、做推演：「大方向 · 接下来约 6 周」，档位和「历史评估：没验证出效果」照旧挨着。
- 悬停：「做推演的结论（大方向）：就是 LEI 说的『模糊的正确』……」。
- 自选股的悬停、刻度条的无障碍标签、做推演依据里的说明、过渡打法的失效句跟着改。
- 文字报告的标题写「0) 大方向（模糊判断）」，skill 文档的小节同名，方便和旧报告、评估对上。

## 理由和出处
- 用户 2026-11-21：模糊判断字面上像不靠谱的判断，不理想；在「大方向 / 成本方向 / 模糊正确 / 往后倾向」里选了大方向。
- 名字说它判断的是什么（接下来约 6 周均线往哪走、对谁有利），不说判断得多精确。SKILL.md 原本就写"用户真正要的是大方向"。
- 没叫「模糊正确」：它自己的历史评估（H1）没通过，叫"正确"和旁边的"没验证出效果"打架。

## 什么情况下重新考虑
- H1 换了评估结论，或换了算法：名字和标签一起看。
