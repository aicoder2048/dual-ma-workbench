# 0008 回测先跑用户的核心名单，不过就停

- 状态：采纳
- 日期：2026-11-20

## 背景
完整计划回测一度安排 86 只票 × 约 3300 个交易日（约 28 万次完整分析，一小时级）。

## 决定
回测和评估先跑核心名单（38 只：指数 / ETF、科技和 AI、2000 亿美元以上大盘股）。不通过就停，不扩大范围；通过了，其余品种列为"待补测"。

## 理由和出处
用户原话："干嘛要回测81只股票的3300个交易日? 太官僚了吧?! 应该先测我最关心的那批……测了不通过, 就不用测剩下的了。"

## 影响
超过十几分钟的计算，开跑前先说规模和预计时间。核心名单在回测页可以一键选。

## 什么情况下重新考虑
无。
