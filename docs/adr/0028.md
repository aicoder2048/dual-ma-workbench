# 0028 结论卡片分清"现在"和"往后"，回测只留本打法，整套方法的免责全页只说一次

- 状态：采纳（随 PR 合并生效；不合并就改写成"不做"）
- 日期：2026-11-21

## 背景
QQQ 2026-11-20 的结论卡片读起来费劲：

- 标题一行写「加速下跌·延伸 接下来几周 明显偏空」。前半句是看大局的结论（趋势类型·阶段），后半句是做推演的模糊判断（`dma_analyze` 的 lean），两句挤在一行，看不出各自是什么。
- 填了成本、处境变成浮盈或浮亏，持仓一行只换了「持仓 · 浮盈」几个字。`plan.ts` 的 PNL 表里每种打法都有浮盈、浮亏各一句建议，只在「找打法」的计划里看得到。
- 对照一行是「MA200 朴素规则：收盘在下方 -10.9%，空仓；双均线也空仓 一致 评估 MAR 0.26 vs 0.14」，缩写和数字混在一起。
- 回测一格把"本打法的历史记录"和"整套方法 86 只票的评估没找到交易优势"写成一段，空仓不买的打法也占一行说"回测没有进场"。

## 决定
只改显示，不动计算和回测。

1. 标题分两段，各带标签：「现在：加速下跌·延伸」「模糊判断 · 接下来几周：明显偏空」。悬停写明各自来自哪一节：现在是看大局判的趋势类型·阶段；模糊判断不预测明天涨跌，只判断接下来几周均线（市场的持仓成本）往哪走、对谁有利。
2. 持仓一行：处境是浮盈或浮亏时，在做法下面显示计划里「盈亏」那一条（PNL 表的句子，成本填进去）。输入成本时照旧只重画这一行。没填成本、持平时不显示，成本输入框旁边提示填了就按浮盈 / 浮亏给建议。
3. 对照写成一句：「MA200 规则：空仓｜双均线：空仓｜一致」，不一致时"不一致"加框、用提醒色。离 MA200 多远、历史评估的数放在悬停里，写成整句：评估比的是收益和回撤之比（MAR，越高越好），MA200 朴素规则 0.26，双均线照方向持有 0.14，一直买入持有 0.33，这一项上朴素规则比双均线好。
4. 回测一行只说本打法：进场规则、笔数、比随机进场多或少多少、90% 区间。范围（几只票、哪段时间）、胜率、中位数在悬停里。打法空仓不买、或这段时间一笔没进场，整行不显示。
5. 整套方法的评估（`EVALUATION_NOTE`）从卡片拿掉，放在中栏三步下面固定一处（`index.html` 的 `#method-note`）。读完三步就看得到，不挤在结论里。

数据字段：
- `RecordNote.text` 照旧是整句、末尾带整套方法的评估，长风的 `回测` 字段、交易日志、问鸿雁的提示词都读它，不变。新增 `card`（卡片的一行和悬停），没有记录时为 `null`。
- `NaiveCompare` 去掉只给卡片用的 `short`（"评估 MAR 0.26 vs 0.14"），加 `ma200`（朴素规则的持有 / 空仓）。`text` 改写成完整的话，信息不变：朴素规则怎么说、离 MA200 多远、双均线怎么说、一不一致、三组 MAR。长风的 `MA200.对照` 字段读的就是它。`rule` 保留。

## 理由和出处
- 用户 2026-11-21 逐条确认了这五处。
- 第 5 条只说一次：同一句风险提示出现在每张卡片上，看多了就不看了。放在三步下面，是读完分析、准备下单前会经过的位置，又不占结论的第一眼。
- 页面上那句和 `record.ts` 的 `EVALUATION_NOTE` 必须一字不差：`app/test/viz.test.ts` 读 `index.html` 对这一句，还查它只出现一次。

## 影响
- 1280×720 下 SPY 2024-04-19 这种有本打法回测的卡片，最后一行（回测）要往下滚一点才看得到；NVDA 这类空仓不买的打法少了这一行。
- 交易日志里存的 `record` 还是整句（带整套方法的评估），在日志条目折叠的详情里。没改：它是记日志那一刻给长风看的同一句话。
- Markdown 报告（`report.ts`）不受影响。

## 什么情况下重新考虑
- 整套方法有了新的评估结论：改 `EVALUATION_NOTE` 时一起改 `index.html` 那一句（测试会先失败）。
- 用户觉得三步下面太靠后、看不到：挪到中栏顶部的数据状态旁边，仍然只放一处。
