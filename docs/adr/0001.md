# 0001 产品定位：把双均线交易系统用到真实交易上

- 状态：采纳
- 日期：2026-11-20

## 背景
2026-11-20 方法评估（六条主张都没过事先定的标准）之后，README、SKILL.md、结论卡片一度被改写成"学习和复盘工具"。

## 决定
归雁的定位是**把双均线交易系统用到真实股票交易上的严肃工具**。盲测练习、识别题库是辅助功能，入口放在顶栏，不占左栏。

## 理由和出处
定位由用户定，不由回测结果定（用户原话："this app is an serious app to apply 双均线交易系统 to real-world stock trading - 这是定位 !!!"）。回测和评估结果如实保留，作为 README 的"风险提示"。

## 影响
功能优先级以实盘为主：完整计划（进场、止损、目标、盈亏比、股数）、持仓、提醒、实盘日志。PR #38、#39。

## 什么情况下重新考虑
用户改变定位时。
