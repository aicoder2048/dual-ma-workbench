# 0004 不用趋势线

- 状态：不做
- 日期：2026-11-20

## 背景
TradingView 有 Auto trendlines、Linear regression channel；外部来源的 123 法则（视频 N，老猫与指标）第一条是"破趋势线"。

## 决定
不画、不计算趋势线；123 法则的"破趋势线"不进规则表。

## 理由和出处
LEI 在视频 G 06:14 说跌破、涨破趋势线"这都不科学"。手画趋势线主观，脚本算出的线也和作者手画的不一致。

## 影响
需要客观化时，按视频 D 18:12 的说法"连两个底部构造"，并标"推断"。

## 什么情况下重新考虑
LEI 的视频里出现客观使用趋势线的规则。
