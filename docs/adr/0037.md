# 0037 识别题加「打法补全」：先判类型，再按找打法的格子逐格选；只考种类，不考价格和仓位

- 状态：采纳
- 日期：2026-11-22

## 背景
「看打法」只考两问：空仓现在怎么做、进场后止损放哪，而且题干直接告诉类型。工作台的「找打法」是固定的格子（ADR 0029）：空仓六格、持仓五格。用户 2026-11-22 要练整套格子，并定了两点：不告诉类型，自己判；空仓、持仓都出。

## 决定
新题型「打法补全」（`fill`）。一份分析出两道：空仓一道，持仓一道（浮盈、浮亏随机一种）。

- **第 0 问判类型**：六个选项，和「看图」同一套词表（类型 × 阶段、过渡状态），题干不写类型。
- **再逐格选**：
  - 空仓五格：能不能做 → 等什么信号 → 在哪进 → 止损放哪 → 目标看哪。
  - 持仓五格：拿着还是走 → 盯什么信号 → 在哪走 → 目标看哪 → 浮盈 / 浮亏怎么办。
- **答案从当天的交易计划取**：
  - 第一格是计划的结论词（`Plan.verdict`），空仓是做 / 等 / 不做，持仓是拿着 / 减仓 / 离场。
  - 止损看空仓计划的止损（不进场写「—」），目标看交易计划的第一阻力是哪一种（缺口、均线密集、全部汇聚、前高，或为什么没有）。
  - 其余每套打法每格一句，写在一张表里（`src/practice/fill.ts` 的 `FILL_PHRASES`，打法 × 处境 × 格）。缺一项单元测试失败。
  - 干扰项取别的打法在同一格的那句，所以每个错选项都是真实存在、只是放错了地方的做法。
- **类型判错时**：后面的格子仍按归雁判的类型给分。交卷后每格多一句「按你选的类型，这格该填什么」，和答案一样的格不写。对得上，说明打法记得，只是类型认错了；对不上，是打法不熟。
- **揭晓**：依据写归雁判的类型和打法、每格的要点（第一格带计划的那句做法），规则编号取计划条目用到的规则。完整的格子（带价位和依据）仍在工作台的「找打法」。
- 只用题库的换算行情，不显示真实代码、日期、价格（ADR 0013）；着色只用自带规则（ADR 0020）。

## 理由和出处
- **不考价格**：价位是脚本照规则算的（抵扣价、EMA20、构造完成价），练的是"这一格该看什么"，不是背数字。选种类也让干扰项可比：几个价位挤在一起时，选对选错常常只是读数准不准。
- **不考仓位**：每套打法的仓位格都是同一句（按止损倒算股数，A6），考了没有区分度。
- **类型判错仍按归雁的类型给分**：用户选了"不给类型"，接受类型错了后面跟着错。每格加一句「按你选的类型」，就能分清两种错，不必为此再拆一道题。
- **持仓只出浮盈、浮亏**：没填成本时第五格只有"去填成本"，没有可考的东西。

## 影响
- 一道题六问：`AnswerInput.picks` 上限从 4 改成 6。
- 六问放不进一屏，右栏自己滚动；交卷后右栏回到顶上，先看到对错。
- 修了一个旧问题：答完一段行情的最后一题时，题库先删这段的图表文件、再给推演揭晓题取真实走势，会读不到文件。现在先取揭晓，再删。新题型改变了出题顺序，单元测试碰到了这种情况。
- `plan.ts` 导出 `PLAY_KEYS`、`HOLD_VERDICT`，短语表按它们核对。

## 什么情况下重新考虑
- 答题记录里某一格大量错在同一个干扰项：那两套打法的短语太像，改写短语。
- 用户觉得类型错了后面全错太挫败：改成给类型的版本，或者第 0 问错了就按所选类型给分。
- `plan.ts` 加了新打法或改了某套打法的条目：短语表跟着改（单元测试会先失败）。
