# 0002 不加通用技术指标（RSI、MACD、Stochastic、CCI 等）

- 状态：不做
- 日期：2026-11-20

## 背景
参照 TradingView 的 Indicators 菜单讨论过要不要加更多指标。

## 决定
不加 RSI、Stochastic、MACD、CCI、Williams %R、Aroon 等震荡和动量指标。

## 理由和出处
方法的核心是"用同一组周期、两种算法的均线看市场成本往哪走"（视频 A）。视频 L（MACD 精解）入库时，"MACD 转色和背离"已列入 rules.md 的"不是规则"。加指标只会在信号打架时干扰判断。

## 影响
图表只画 MA/EMA 20/60/120（加 MA200 对照）和方法里已有的东西（抵扣价、构造、缺口、筹码分布）。

## 什么情况下重新考虑
LEI 的视频里出现明确使用某个指标的规则，并且入库核过原话。
