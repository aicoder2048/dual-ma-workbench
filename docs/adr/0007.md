# 0007 外部作者的视频单列 X 编号，冲突以 LEI 为准

- 状态：采纳
- 日期：2026-11-20

## 背景
2B 那期视频来自另一位作者（老猫与指标），和 LEI 的说法有 4 处冲突（趋势线、2B 之后的确认、2B 用在哪、大方向怎么定）。

## 决定
外部来源的规则放进 rules.md 的"外部交叉引用（非 LEI）"小节，编号 X1、X2……，一律"需看图"，不进工作台规则清单；冲突处 LEI 的规则不改，只加"对照"。

## 理由和出处
方法以 LEI 为准；外部说法只补 LEI 没讲到的空白，并且标明来源，不和 LEI 的说法混在一起。

## 影响
入库 skill 写明外部视频的处理方式。PR #37。
