双均线概念图解

工作台上每个术语一页：一张示意图、算和不算的对照、规则编号和视频出处。按读图的顺序排，从均线本身读起。图都是示意，不是真实行情。

总纲

  • 五种趋势类型加速上涨、稳定上涨、横盘、稳定下跌、加速下跌，和定不出类型时
  • 大方向LEI 说的"模糊的正确"：接下来约 6 周成本往哪走

均线本身

  • 抵扣价MA 明天要扣掉的那根收盘，决定 MA 往哪走
  • 拐头EMA 看线本身，MA 看抵扣价
  • 几点钟方向均线的斜率：走平、有斜率、加速

线和线的关系

  • 排列6 条线谁在上谁在下：多头、空头、混乱
  • 交叉 / 双交叉金叉、死叉，MA 和 EMA 两对都交叉
  • 均线密集短中长期成本一致的地方

价格和线的关系

  • 破线收盘穿过 MA20 和 EMA20 两条线
  • 乖离价格离均线多远，是不是加速

转折

  • 五个进度点破线 → EMA 拐头 → MA 拐头 → 第一个交叉 → 双交叉
  • 顶部 / 底部构造高点、低点怎么排才算构造完成
  • 关键性波动20 线组一起换方向的那一下

计划

  • 第一阻力 / 目标位和盈亏比上方第一道阻力，值不值得做
  • 缺口没成交过的价格区间
  • 筹码山按价格堆起来的成交量，只作参考
