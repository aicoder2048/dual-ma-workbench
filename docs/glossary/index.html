双均线概念图解

工作台上的术语，每个一页：示意图、算和不算的对照、规则编号、视频出处。按读图顺序排。图是示意，不是真实行情。

总纲

  • 五种趋势类型五种类型，和定不出类型时
  • 大方向接下来约 6 周成本往哪走

均线本身

  • 抵扣价MA 明天扣掉的收盘价
  • 拐头EMA 看线，MA 看抵扣价
  • 几点钟方向均线的斜率

线和线的关系

  • 排列6 条线的上下次序
  • 交叉 / 双交叉金叉、死叉，两对都交叉
  • 均线密集短中长期成本一致

价格和线的关系

  • 破线收盘价穿过 MA20 和 EMA20
  • 乖离价格离均线多远

转折

  • 五个进度点破线 → EMA 拐头 → MA 拐头 → 第一个交叉 → 双交叉
  • 顶部 / 底部构造高点、低点怎么排才算完成
  • 关键性波动20 线组一起换方向

计划

  • 第一阻力 / 目标位和盈亏比上方第一道阻力，值不值得做
  • 缺口没成交过的价格区间
  • 筹码山按价格堆的成交量，只作参考
